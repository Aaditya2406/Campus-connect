CampusConnect
A campus feedback application developed as part of a Cloud Computing laboratory project at KLE Technological University.

CampusConnect allows users to submit feedback through a web interface. The frontend sends requests to a FastAPI backend, which stores feedback in a MySQL database. The application is containerised with Docker and deployed using Kubernetes.
Technology Stack
- Frontend: HTML, CSS, JavaScript
- Web server: Nginx
- Backend: Python, FastAPI
- Database: MySQL
- Containerisation: Docker
- Orchestration: Kubernetes
